The `LSBImageStego` attack method encodes a text prompt into the least significant bits (LSBs) of a lossless PNG image and returns a `data:image/png;base64,...` data URI.

## Usage

```python title="main.py"
from deepteam import red_team
from deepteam.vulnerabilities import Bias
from deepteam.attacks.single_turn import LSBImageStego
from somewhere import your_callback

lsb_stego = LSBImageStego(weight=2)

red_team(
    attacks=[lsb_stego],
    vulnerabilities=[Bias()],
    model_callback=your_callback,
)
```

There are **SIX** optional parameters when creating an `LSBImageStego` attack:

- [Optional] `weight`: an integer that determines this attack method's selection probability, proportional to the total weight sum of all `attacks` during red teaming. Defaulted to `1`.
- [Optional] `carrier_image_path`: path to an existing carrier image. Defaulted to `None`.
- [Optional] `channels`: pixel channel mode (`"RGB"` or `"RGBA"`). Defaulted to `"RGBA"`.
- [Optional] `delimiter`: sentinel string appended after the UTF-8 payload. Defaulted to `"====EOF===="`.
- [Optional] `min_dimensions`: minimum `(width, height)` for generated carrier images. Defaulted to `(64, 64)`.
- [Optional] `background_color`: RGB or RGBA tuple (`0..255`) for generated carrier images. Defaulted to `(240, 244, 248, 255)`.

### As a standalone

You can enhance any attack using the `enhance` method and decode it with `decode_image`:

```python
from deepteam.attacks.single_turn import LSBImageStego

base_attack = "Your initial harmful prompt targeting a specific vulnerability"
lsb_stego = LSBImageStego()

enhanced_attack = lsb_stego.enhance(base_attack)
decoded_attack = LSBImageStego.decode_image(enhanced_attack)
print(decoded_attack)
```
