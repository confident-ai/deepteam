The `CharSplit` attack method appends output-formatting instructions asking the target model to insert a single non-whitespace delimiter (`.` by default) between adjacent letters inside each word of its response, and provides `CharSplit.decode` to normalize the response back to plain text.

## Usage

```python title="main.py"
from deepteam import red_team
from deepteam.vulnerabilities import Bias
from deepteam.attacks.single_turn import CharSplit
from somewhere import your_target_llm

char_split = CharSplit(weight=2, delimiter=".")


def model_callback(input: str) -> str:
    return CharSplit.decode(your_target_llm(input), delimiter=".")


red_team(
    attacks=[char_split],
    vulnerabilities=[Bias()],
    model_callback=model_callback,
)
```

There are **THREE** optional parameters when creating a `CharSplit` attack:

- [Optional] `weight`: an integer that determines this attack method's selection probability, proportional to the total weight sum of all `attacks` during red teaming. Defaulted to `1`.
- [Optional] `delimiter`: a single non-whitespace character inserted between adjacent letters inside each word. Defaulted to `"."`.
- [Optional] `action`: `"encode"` to append output-formatting instructions, or `"decode"` to normalize formatted text back to plain text. Defaulted to `"encode"`.

### As a standalone

You can enhance any attack using the `enhance` method and decode responses with `CharSplit.decode`:

```python
from deepteam.attacks.single_turn import CharSplit

base_attack = "Your initial harmful prompt targeting a specific vulnerability"
char_split = CharSplit(delimiter=".")

enhanced_attack = char_split.enhance(base_attack)
print(enhanced_attack)

decoded_response = CharSplit.decode("H.e.l.l.o c.o-o.p.", delimiter=".")
print(decoded_response)
```
